# ZAPRET GUI 2.0 (Rust)

Переписанный на Rust ZapretGUI: стратегии zapret (`winws.exe`), TgWsProxy, обновления,
диагностика — и новый **системный прокси-туннель с kill switch**.

`..\ZapretGUI.exe` — собранная версия. Старый exe на C# сохранён в `_backup\ZapretGUI-csharp-1.0.exe`.
Настройки (`ZapretGUI.ini`) и задача автозапуска остались прежними.

## Интерфейс

Окно без системной рамки: свой заголовок в цвет интерфейса (как в Discord), скруглённые углы в Windows 11. Боковое меню: **Обзор** (три карточки: обход, прокси, Telegram + последние события),
**Стратегии** (поиск, двойной клик — запуск, игровой фильтр, тесты), **Прокси**, **Telegram**
(все настройки TgWsProxy прямо в окне), **Настройки** (запуск, обновления, инструменты), **Журнал**.
Окно на egui + OpenGL: ~4 МБ exe, ~80 МБ памяти, перерисовка только при изменениях.
**Оформление** (Настройки): темы «Графит», «Тёплая», «Полночь», «OLED», «Светлая» и 7 цветов акцента, применяются сразу.
Закрытие прячет в трей; иконка в трее показывает статус точкой (зелёная — работает, красная — kill switch блокирует).

## Прокси-туннель

* Движок — `bin\sing-box.exe` (SagerNet/sing-box 1.14): TUN-адаптер `ZapretTun` с `auto_route` +
  `strict_route` перехватывает системный трафик с учётом исключений и возможностей прокси.
* Поддерживаются **SOCKS5** и **HTTP** с логином/паролем. Импорт строкой:
  `socks5://user:pass@host:port`, `http://host:port`, `host:port:user:pass`.
* DNS идёт через прокси (DNS-over-HTTPS 1.1.1.1 / 8.8.8.8 / 9.9.9.9 / 77.88.8.8) — без утечек DNS.
* Исключения: программы (`Discord.exe`) и домены (`gosuslugi.ru`) можно пустить напрямую —
  на них продолжает работать обход zapret. Локальная сеть — напрямую (переключатель).
* HTTP CONNECT передаёт только TCP: DNS идёт через DoH, остальной UDP вне исключений автоматически
  отклоняется, даже если переключатель QUIC выключен. Для голоса/игр нужен SOCKS5 с поддержкой UDP либо VPN.
* «Блокировать QUIC» отключает UDP 443 для SOCKS5, чтобы браузеры переходили на TCP.
* По умолчанию DNS возвращает только IPv4; соединения IPv6 вне прямых исключений отклоняются.
  «IPv6 через прокси» включайте при поддержке IPv6 сервером: иначе возможны ответы 502 от HTTP-прокси.
* Кнопка «Проверить прокси» проверяет CONNECT к `cp.cloudflare.com:443`, TLS с проверкой сертификата
  и ответ HTTPS, затем показывает задержку.
* Конфигурация проверяется командой `sing-box check` до изменения WFP и маршрутов.
  Если другой VPN перехватывает маршрут к прокси, отключите его перед подключением туннеля.
* Пароли хранятся в `ZapretGUI.proxy.json` зашифрованными DPAPI (только ваша учётная запись Windows).

### Kill switch

Сделан на Windows Filtering Platform (`src/killswitch.rs`): отдельный подуровень WFP с правилом
«блокировать всё» и узкими разрешениями — loopback, сам `sing-box.exe`, IP прокси-сервера, DHCP,
локальная сеть (если разрешена) и интерфейс туннеля. Если sing-box упадёт, его адаптер исчезает —
и трафик никуда не уходит, пока туннель не поднимется снова (автопереподключение включено по умолчанию).

Правила переживают падение самого ZapretGUI (чтобы не было утечки), но **не** перезагрузку —
заблокировать себя навсегда невозможно. При обычном выходе и по кнопке «Отключить» / «Снять блокировку»
правила удаляются; при следующем запуске оставшиеся от сбоя правила снимаются автоматически.

## Сборка

Нужен Rust (`rustup`, toolchain `stable-x86_64-pc-windows-gnu` — Visual Studio не требуется).
Запустите `build.bat`: соберёт и положит `ZapretGUI.exe` в папку zapret.

`Cargo.lock` закреплён на версиях `parking_lot`, `native-tls`, `libloading`, `webbrowser`, которые
ещё не используют `windows-link` (raw-dylib требует `dlltool`+`as`, которых нет в GNU-toolchain без MinGW).
`build.rs` встраивает манифест `requireAdministrator` и многомасштабную иконку из `installer/app.ico`,
а также подкладывает `shlwapi.dll` для линковки. `build_resources.rs` создаёт COFF-ресурсы без windres/SDK.
`build.bat` не завершает работающее приложение: для установки сборки сначала выйдите через трей.

Для разработки: `ZAPRET_NO_MANIFEST=1 cargo test` и запуск без прав `ZapretGUI.exe --preview --page=N`.
Сетевые тесты запускаются отдельно: задайте `ZAPRET_LIVE_PROFILE` (путь к локальному JSON профилей)
и `ZAPRET_LIVE_ENGINE` (путь к sing-box), затем `cargo test live_ -- --ignored --nocapture`.
Они проверяют HTTPS через сохранённый прокси и sing-box, DNS A/AAAA через DoH с локальными слушателями;
системные маршруты и WFP не меняют. Полную проверку TUN/kill switch проводите отдельно с правами администратора.

## Файлы

| Файл | Что внутри |
|---|---|
| `main.rs` | права, single-instance, поиск папки zapret |
| `ctl.rs` | контроллер: состояние, процессы, все действия в фоновых потоках, мониторинг туннеля |
| `ui.rs`, `theme.rs`, `icon.rs` | окно, страницы, трей, стиль, иконка |
| `zapret.rs` | разбор .bat, игровой фильтр, списки, версия |
| `proxy.rs` | профили, разбор строк, конфиг sing-box, проверка прокси |
| `killswitch.rs` | WFP kill switch |
| `tg.rs` | TgWsProxy: процесс, config.json, значок в трее |
| `updater.rs` | обновления zapret и TgWsProxy |
| `diag.rs` | диагностика, кэш Discord, автозапуск |
| `sys.rs`, `cfg.rs`, `paths.rs`, `logbuf.rs` | Win32-обёртки, ini, пути, журнал |

## Установка и обновления для коллег

**Установка:** скачайте `ZapretGUI-Setup-<версия>.exe` со страницы
[Releases](../../releases/latest) и запустите. Установщик ставит ZapretGUI в `C:\Program Files\ZapretGUI`
вместе с официальным релизом zapret, TgWsProxy и sing-box. Windows SmartScreen может предупредить
о неподписанном файле: «Подробнее» → «Выполнить в любом случае».

**Обновления:** приложение проверяет релизы этого репозитория при запуске и каждые 6 часов.
Найдя новую версию, скачивает установщик, сверяет SHA-256 с файлом `.sha256` из релиза и
**ставит её само** (переключатель «Обновлять автоматически» в настройках; выключенный — появляется
кнопка «Обновить ZapretGUI»). Установка идёт тихо, приложение перезапускается, включает то, что
работало (обход, прокси, TgWsProxy), и показывает окно «Что нового» с текстом релиза.
Так же автоматически обновляются zapret и TgWsProxy.
Пользовательские списки, настройки и прокси-профили при обновлении сохраняются.

**Выпуск новой версии** (для автора):

```bat
release.bat -Version 2.0.1 -Publish -NotesFile notes.md
```

Скрипт поднимет версию, соберёт exe, подготовит чистый комплект (официальный zapret, TgWsProxy,
sing-box — ничего из вашей локальной папки), соберёт установщик Inno Setup, посчитает SHA-256
и опубликует GitHub Release с двумя файлами. Текст релиза (Markdown: `## Заголовок`, `- пункт`)
пользователи увидят в окне «Что нового»; без `-Notes`/`-NotesFile` он собирается из коммитов с прошлого релиза. Нужны Rust (GNU), Inno Setup 6 и `gh auth login`.
